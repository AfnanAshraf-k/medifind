## 📊 How to Open the Presentation

1. Open `MediFind_Presentation.html` in any modern web browser (Chrome recommended)
2. Use **← →** arrow keys or click **Previous / Next** buttons to navigate slides
3. Press **F** key to enter Fullscreen mode
4. There are **16 slides** covering all required sections

---

## 📄 How to Open / Save the Project Report

1. Open `MediFind_Project_Report.html` in any modern web browser
2. To **save as PDF**: Press `Ctrl+P` → Select "Save as PDF" → Save
3. To **print**: Click the 🖨️ Print button in the top bar, or press `Ctrl+P`
