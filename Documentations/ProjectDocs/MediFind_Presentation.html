📖 Introduction
What is MediFind?
🌐
Domain
Healthcare Technology — Hyperlocal digital pharmacy directory connecting patients with nearby medicine stock in real time.
💡
Core Idea
Search medicine by brand or generic name → see which nearby pharmacies have it in stock → reserve it online & upload your prescription.
📍
Where it is Used
Primarily targeting Perinthalmanna & Valanchery in Malappuram district, Kerala — easily scalable statewide.
🔑 Key Actors
  • Patients / Users – Search medicines, make reservations, upload prescriptions
  • Pharmacy Owners – Manage live inventory, verify prescriptions, fulfil orders
  • Administrators – Oversee platform data and pharmacy registrations
🚀 Why It Matters
During medical emergencies, every minute counts. MediFind eliminates the need to physically visit multiple pharmacies or make dozens of calls — replacing hours of search with a 30-second digital query.

🎯 Objectives
Project Objectives
  1. 01
    Real-Time Medicine Search
    Enable instant full-text search across brand names (Dolo 650, Augmentin) and generic names (Paracetamol, Amoxicillin) across all registered pharmacies simultaneously.
  2. 02
    GPS-Based Proximity Sorting
    Compute real-time distances to pharmacies using the Haversine spherical formula and present results sorted by closest proximity automatically.
  3. 03
    Online Medicine Reservation System
    Allow patients to reserve specific medicine quantities from pharmacies, preventing stock exhaustion before they physically travel to the store.
  4. 04
    Digital Prescription Upload & Verification
    Enable patients to attach doctor prescriptions (PDF / PNG / JPG) to reservations; pharmacy owners verify via high-resolution modal before dispensing.
  5. 05
    Automated Inventory Control via DB Triggers
    Implement PostgreSQL trigger-based automatic stock decrement when an order is marked "Collected", ensuring inventory accuracy without manual intervention.

⚠️ Problem Statement
The Problem We Are Solving
❌
Existing Problems
  • Time-Wasting Physical Visits: Patients visit multiple shops during emergencies with no availability guarantee
  • National Apps Too Slow: Tata 1mg, PharmEasy deliver in 24–48 hours — useless for emergencies
  • Prescription Rejection at Counter: Issues discovered only after waiting in queue

Who Faces This?
Patients and caregivers in Perinthalmanna & Valanchery — semi-urban towns in Malappuram, Kerala — particularly during acute medical emergencies.
✅
How MediFind Solves It
  • Instant Search: One search replaces hours of calls and visits
  • Live Stock Status: Pharmacists update inventory in real time
  • Online Reservation: Reserve before you travel — stock is held for you
  • Digital Prescription: Upload and verify document before arriving at counter
  • Free for Pharmacies: Zero commission — any local chemist can join
Key Insight: Traditional e-commerce pharmacy apps focus on warehouse-to-doorstep delivery. MediFind focuses on hyperlocal counter-pickup within minutes — a completely different use case ignored by existing solutions.

Key Implementation Details

Haversine Geolocation Algorithm

export function calculateDistance(
  lat1: number, lon1: number,
  lat2: number, lon2: number
): number {
  const R = 6371; // Earth radius in km
  const dLat = (lat2-lat1) * (Math.PI/180);
  const a = Math.sin(dLat/2)**2 +
    Math.cos(lat1*0.01745) * Math.cos(lat2*0.01745)
    * Math.sin(dLon/2)**2;
  return parseFloat((R * 2*atan2(√a, √(1-a))).toFixed(1));
}

PostgreSQL Auto-Decrement Trigger

CREATE OR REPLACE FUNCTION
  decrement_stock_on_collection()
RETURNS trigger AS $$
BEGIN
  IF new.status = 'collected'
    AND old.status != 'collected' THEN
    UPDATE pharmacy_stock
    SET quantity = GREATEST(0, quantity - new.quantity)
    WHERE id = new.pharmacy_stock_id;
  END IF; RETURN new;
END; $$ LANGUAGE plpgsql;
